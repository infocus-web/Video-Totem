# Modelo de orientación facial

BlazeFace short-range, float16, versión 1, distribuido por Google MediaPipe.

- [Documentación oficial y modelos](https://developers.google.com/edge/mediapipe/solutions/vision/face_detector)
- [Archivo de origen](https://storage.googleapis.com/mediapipe-models/face_detector/blaze_face_short_range/float16/1/blaze_face_short_range.tflite)
- [Model card](https://storage.googleapis.com/mediapipe-assets/MediaPipe%20BlazeFace%20Model%20Card%20%28Short%20Range%29.pdf), licencia del modelo Apache-2.0.
- Biblioteca: `@mediapipe/tasks-vision@0.10.32`, licencia Apache-2.0.
- [Copia de la licencia Apache-2.0](LICENSE.txt).

Archivo local: `blaze-face-short-range.tflite`.
SHA-256: `b4578f35940bf5a1a655214a1cce5cab13eba73c1297cd78e1a04c2380b0152f`.

El modelo se incluye para que el análisis no dependa de un CDN externo. El navegador descarga el modelo y una variante de WASM solo al activar Giro inteligente. Las fotos y los resultados se procesan localmente. No se incluyen fotografías personales ni claves API.
